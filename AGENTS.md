# Flow

Flow is a modular, customizable skill-based workflow for brainstorming, design, task planning, and implementation.

Skills live in `skills/`.

See `README.md` for the full workflow.

## Writing Best Practices

- Keep skills focused, concise, readable, and unopinionated.
- Prefer clear instructions over verbose explanations.
- Avoid unnecessary complexity.
- Make skills easy to adapt independently.
